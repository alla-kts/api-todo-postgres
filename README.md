# API Todo Postgres

API REST para gerenciamento de tarefas simples
Projeto em desenvolvimento, futuramente aplicação do login para usuarios

---

## Tecnologias

* Node.js
* Express.js
* PostgreSQL

---

## Funcionalidades

* Criar tarefa
* Visualizar todas as tarefas
* Visualizar tarefa específica
* Atualizar tarefa
* Deletar tarefa

### Futuramente

* Sistema de login
* Cadastro de usuários
* Autenticação

---

## Estrutura do projeto

```
 config/        # conexão com banco
 repository/    # acesso aos dados
 service/       # regras de negócio
 controller/    # lógica das rotas
 middlewares/   # middlewares
 routes/        # definição das rotas
 server.js      # inicialização do servidor
```
